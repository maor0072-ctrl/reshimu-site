# reshimu.co.il - הרב יעקב מאור

אתר סטטי (HTML + CSS בלבד, בלי מסגרות ובלי npm): ייעוץ, יצירת קשר, וספרים.
מתפרסם ב-GitHub Pages מענף `main`, על הדומיין `reshimu.co.il` שה-DNS שלו בקלאודפלייר.

## המבנה

```
pages/*.html        גוף העמוד בלבד (בלי כותרת עליונה, ניווט ותחתית)
_shell-head.html    הכותרת, הניווט ותגי ה-meta שכל עמוד חולק
_shell-foot.html    התחתית
build.py            מרכיב מכל אלה את קבצי ה-HTML שבשורש
assets/style.css    גיליון העיצוב
worker/lead.js      צד השרת של טופס יצירת הקשר (Cloudflare Worker)
```

**לא עורכים ידנית את קבצי ה-HTML שבשורש** - הם נוצרים מחדש בכל בנייה ונדרסים.
עורכים את `pages/`, ואז:

```
py build/reshimu-site/build.py
git add -A && git commit -m "..." && git push
```

## טופס יצירת הקשר

האתר סטטי ולכן אין לו צד שרת. `worker/lead.js` הוא כל צד השרת: הוא רץ על
Cloudflare Workers (בחינם) בכתובת `reshimu-lead.maor0072.workers.dev`, מקבל
את הטופס ושולח מייל דרך Composio אל הג'ימייל המחובר. **שום שירות טפסים
חיצוני לא רואה את הלידים.** מפתח Composio מוזרק כסוד של ה-Worker ואינו בקוד.

הכתובת שאליה הטופס פונה מוגדרת ב-`build.py` תחת `LEAD_ENDPOINT`.

### שתי מלכודות שנצרבו כאן בדם

**המייל נבנה כ-MIME ידני ולא דרך `GMAIL_SEND_EMAIL`.** הכלי המובנה שולח את
הגוף בלי להצהיר על קידוד, וג'ימייל מפרש אותו כ-ASCII. כאן הכותרת מקודדת
ב-RFC 2047 והגוף ב-base64 עם `charset=UTF-8` מפורש.

**אסור להסתיר את שדה מלכודת הספאם בקיזוז שלילי** (`left:-9999px`). במסמך
`dir="rtl"` זה מותח את רוחב המסמך לעשרת אלפים פיקסלים ודוחף את כל התוכן
מחוץ למסך - הדף נראה ריק לגמרי. ההסתרה הנכונה: `clip:rect(0 0 0 0)`.

## פריסה

כל דחיפה ל-`main` עולה לאוויר תוך כדקה. ה-Worker נפרס בנפרד דרך ה-API של
קלאודפלייר (אין wrangler על המכונה).

## מסירת הספר "כוח האמונה" - אוטומטית

עמוד הספר מחזיק טופס של ארבעה שדות: שם ומשפחה, טלפון נייד ודוא"ל כשדות
חובה, וכתובת מגורים כשדה רשות. הטופס שולח ל-Worker עם
`kind: "book"`, וה-Worker עושה שני דברים: שולח את הספר לפונה ומודיע ליעקב.

**הנייד נבדק פעמיים - בדפדפן וגם ב-Worker.** הבדיקה בדפדפן לבדה ניתנת
לעקיפה, ובלי מספר תקין הרישום מחמיץ בדיוק את מה שהוא נועד לאסוף. הכלל:
נייד ישראלי (`05X`, עם או בלי `972`), או מספר בינלאומי עם `+` ו-9 ספרות
ומעלה. מי שכבר הוריד לפני 2026-09-08 רשום בלי טלפון, וזה בסדר - לא נעשה
מילוי למפרע.
**הקישורים גם נחשפים על המסך מיד אחרי השליחה** - גם אם המייל נכשל, אף אחד
לא נשאר בלי הספר.

הקבצים יושבים בריפו תחת `files/`:

```
files/koach-haemuna-phone.pdf    מהדורת A6 לקריאה בטלפון
files/koach-haemuna.pdf          מהדורת A4 למחשב
```

המקור החי שלהם הוא `books/output/` ב-AIOS. שינוי בספר מחייב העתקה מחדש לכאן.

**ההתראה ליעקב לא נשלחת ל-`info@reshimu.co.il`.** הכתובת קיימת ומועברת לאותה
תיבת ג'ימייל, וג'ימייל מדכא עותק של הודעה שהוא עצמו שלח. הנושא הקבוע
`הורדת הספר: <שם>` הוא מה שמאפשר סינון ותיוג.

## פריסת ה-Worker

אין wrangler על המכונה. הפריסה היא העלאת מודול דרך ה-API של קלאודפלייר:

```
PUT /accounts/<account>/workers/scripts/reshimu-lead
multipart: metadata={"main_module":"lead.js","keep_bindings":["secret_text"]} + lead.js
```

**`keep_bindings` הוא לא קישוט.** בלעדיו העלאה חדשה מוחקת את הסוד
`COMPOSIO_API_KEY` וכל שליחת המייל מתה בשקט.
